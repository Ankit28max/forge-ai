# Forge

A cloud-based AI coding agent built from scratch.

## Goal

Forge allows users to connect a GitHub repository and give
an AI agent coding tasks. The agent operates inside an
isolated sandbox, modifies code, runs tests, and can
eventually create commits and pull requests.
